# 🛡️ ShieldGuard — Security & Surveillance Web Template

A modern, responsive web template designed for **private security companies** offering manned guarding, rapid response, CCTV, electric fencing, automated gates, and alarm installations.

> **Showcase Template:** This project is a demonstration template built to show prospective security clients how a dedicated website can generate leads, streamline guard applications, and present services clearly. All company details, license numbers, contact numbers, and sample rates shown are **placeholders for demonstration purposes**.

---

## ✨ Key Features

### For Security Companies (Lead Generation & Operations)
* **Guarding Cost Calculator:** Lets prospective clients estimate monthly costs by service, guard count, contract length (with multi-month discounts), and add-ons (K9, supervisor visits, CCTV monitoring), then pass details toward the quote form.
* **Electric Fence Estimator:** Quick meter-based calculation helper inside the installations section.
* **Guard Recruitment & Screening Form:** Collects applicant details and credentials (age, ID, height, O-levels, ex-police/military background, PSA certification, fitness/run benchmark, driving licence, first aid, criminal record disclosure) with instant score feedback.
* **Quote & Inquiry Flow:** Captures client type, service area, service needed, urgency level, and project notes.
* **Emergency / Rapid Response Modal:** Prominent emergency trigger and dispatch form alongside 24/7 control room callouts.
* **Client Request Tracker ("My Requests"):** Stores submitted quotes, applications, and emergency logs locally in the browser with filtering and clear options.

### User Experience
* **Search & Filtering:** Filter guarding services by shift/type, installations by category, and job openings by location or employment type.
* **Dark Mode & Responsive Layout:** Adapts across mobile, tablet, and desktop screens.
* **Interactive Modals & Widgets:** Includes product installation quote modals, safety tips, and live status/widget elements.
